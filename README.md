# Task Manager

Консольный менеджер задач. Версия 0.1.0. Задачи хранятся в `tasks.txt` рядом с программой.

Модули: `main.py` (меню и цикл), `core.py` (создать/изменить/удалить), `view.py` (вывод), `utils.py` (`check_confirm`), `storage.py` (txt).

Документация: `BACKLOG.md` — история версий, `BUGFIX.md` — найденные баги.

Запуск: `python main.py`
